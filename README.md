🍽️ Daily Calorie Supply Analysis


1. Project Overview

This project analyses the daily calorie supply per person across countries and over time. The analysis focuses on identifying differences in calorie availability between countries, developments over time, and patterns across regions and country groups.

The project combines Python-based data analysis with an interactive Power BI dashboard to transform the dataset into clear and accessible insights.

2. Project Objectives

The main objectives of this project are to:

Analyse daily calorie supply per person across countries and years.
Identify trends and changes in calorie supply over time.
Compare calorie supply between countries and regions.
Explore differences in calorie supply distributions.
Use Python and Pandas to clean, transform, and analyse the data.
Visualise the results in an interactive Power BI dashboard.
Translate the analysis into clear and meaningful business insights.
3. Tools & Technologies
Python – Data analysis and data preparation

Key features include:

📉 Distribution and comparison of calorie supply levels
📅 Analysis across different years

5. Key Insights

The analysis provides insights into:

Differences in daily calorie supply between countries.

Countries with relatively high or low calorie availability.
